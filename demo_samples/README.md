# Demo Samples Guide

Place your repeatable demo files in this folder.

Suggested names:

- `image_real_01.jpg`
- `image_real_02.jpg`
- `image_fake_01.jpg`
- `image_fake_02.jpg`
- `video_real_01.mp4`
- `video_real_02.mp4`
- `video_fake_01.mp4`
- `video_fake_02.mp4`

Good choices:

- real selfie photos
- short real phone videos
- public celebrity talking-head clips
- AI-generated fake face images
- known fake/deepfake short videos

Keep videos:

- short
- clear
- one visible face
- front-facing when possible

Do not commit private personal media if the repository will be shared publicly.
